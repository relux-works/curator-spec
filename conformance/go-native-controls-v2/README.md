# Unreleased Go native controls v2 corpus

This namespace adds Linux to the exhaustive inventory for Protocol Core §4.2.1
and Manager Profile §2.2.1. The released rc.14 `conformance/v1` corpus and
`conformance/candidate.json` remain byte-identical to their tag. The predecessor
inventory metadata is scoped to that historical corpus; no wire evidence field
reports an inventory version. Its unknown evidence-record-version case rejects
`capability-evidence-v2`, not this successor inventory identity.

`go-host-execution-policy.json` is generated by `go run ./tools/generate-vectors -root .`.
The closed schema is `schemas/go-native-controls-v2/go-host-execution-policy.schema.json`;
`tools/validate.py` validates its schema and full policy semantics alongside the
frozen predecessor. `python -B -m unittest discover -s tools -p 'test_*.py'` includes
paired corpus/version and lost-Linux controls. This is unreleased specification
data, not a release, installed artifact invalidation or runtime qualification.
The historical policy protocol-version metadata is retained; the inventory's
v2 identity and this namespace identify the amendment.
