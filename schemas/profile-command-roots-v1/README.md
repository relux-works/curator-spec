Closed B-a fragment members, inventory, root receipt, generation marker, retained reference,
launcher state, snapshot retention, session pin and corpus schemas for the
[command-root contract](../../protocol/profile-command-roots.md).
Inherited Slice A types retain their digest-prefix and native metadata meaning.

and alternate streams refuse. Semantic bindings and all lifecycle rules are
checked independently by `tools/profile_command_roots.py`; schema acceptance
alone is not authority or runtime qualification. No lock/config/journal number
is allocated by these additive files.

`fragment-members.schema.json` is a non-emittable projection with no fragment
token. The sole whole-object v5 definition remains coordinated rc7 v5, including
sole Codex `codex_settings` ownership. The validator's in-memory fixture composition
adds these required members and models B-a Windows paths/profile grammar; it
cannot authorize emission. Joint carrier acceptance and R2 locations/aggregate/
Windows pinning remain closed gates in the contract.
